---
title: Theming
description: Customize system appearance with Stylix and base16 color schemes
---

Marchyo themes the system from two coordinated sources. The core desktop surfaces — GTK, Hyprland, Waybar, Mako, Ghostty, fzf, bat, hyprlock, starship, the console, the Vicinae launcher, and the Plymouth boot splash — are themed directly from the [Jylhis Design System](https://github.com/jylhis/design) (their Stylix targets are explicitly disabled). [Stylix](https://github.com/danth/stylix) supplies the base16 color scheme and fonts, and themes everything else — Qt, fontconfig, and the remaining targets.

The launcher is a slightly different case, and split by shell: with `marchyo.shell.enable` the in-shell launcher themes itself from the design tokens at runtime (the shell's `Color` singleton — no registration needed), while the discrete stack's Vicinae gets two real themes (`jylhis-dark` for dark, `jylhis-light` for light) generated from the design tokens and registered both, so the full color surface — text, inputs, buttons, list and grid selection, scrollbars, tooltips — is covered rather than just the background/accent basics. See [Launcher](/docs/configuration/launcher/).

## Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `marchyo.theme.enable` | `bool` | `true` | Enable the theming system |
| `marchyo.theme.variant` | `"dark"` or `"light"` | `"dark"` | Theme variant preference |
| `marchyo.theme.scheme` | `string` or `null` | `null` | Override the base16 color scheme (a tinted-schemes catalog name) |
| `marchyo.theme.fontScale` | `number` (0.5–4.0) | `1.25` | Global font-size multiplier applied to every text surface |
| `marchyo.theme.themes` | `list of string or inline base16 theme` | `["jylhis-dark" "jylhis-light"]` | Themes available for runtime switching (pre-built into the closure) |
| `marchyo.theme.wallpaper.enable` | `bool` | `true` | Enable the generated Marchyo grid wallpaper where supported |
| `marchyo.theme.wallpaper.package` | `package` | `pkgs.marchyo-wallpapers` | Package providing generated Marchyo wallpaper assets |

## Basic usage

```nix
marchyo.theme = {
  enable = true;
  variant = "dark";
};
```

## Color schemes

By default the theme is the [Jylhis Design System](https://github.com/jylhis/design) palette, derived from its `themes/jylhis.json`:

| Variant | Palette |
|---------|---------|
| `"dark"` | Jylhis Dark (the "Negative" mode) |
| `"light"` | Jylhis Light (the "Print" mode) |

Both variants sit on a cool, near-neutral ground with a single bronze
interactive accent, a benchmark-vermilion brand mark, and a structural contour
blue used for linework only. Code colors are Emacs Modus Operandi (light) /
Vivendi (dark), so syntax reads identically in every editor and terminal.

To use a different base16 scheme instead, set `marchyo.theme.scheme` to the name of a `.yaml` file in the [tinted-theming/schemes](https://github.com/tinted-theming/schemes) catalog (the `base16/` directory):

```nix
marchyo.theme = {
  variant = "dark";
  scheme = "gruvbox-dark-medium"; # any tinted-schemes catalog name, e.g. "nord"
};
```

## Fonts

Stylix carries the design system's three type roles across the system. The
defaults are:

| Role | Family | Package |
|------|--------|---------|
| Display / headings (`serif`) | Zilla Slab | `pkgs.zilla-slab` |
| Body (`sansSerif`) | Hanken Grotesk | `pkgs.hanken-grotesk` |
| Monospace | BlexMono Nerd Font (IBM Plex Mono, Nerd Font patched) | `pkgs.nerd-fonts.blex-mono` |

The Nerd Font patch of IBM Plex Mono is used for monospace because the desktop
chrome — Waybar, Mako, hyprlock, Ghostty — needs the icon glyphs. To use a
different stack, set the Stylix font options directly:

```nix
stylix.fonts.monospace = {
  package = pkgs.nerd-fonts.jetbrains-mono;
  name = "JetBrainsMono Nerd Font";
};
```

### Font size

`marchyo.theme.fontScale` is a single multiplier that resizes **every** text
surface at once — the Stylix-driven apps (Qt, fontconfig, GNOME/KDE) and the
directly-themed chrome alike (the terminal, Waybar, notifications, the lock
screen, the launcher, GTK apps, and the TTY console). It defaults to `1.25`
(noticeably larger than upstream defaults). Set it to `1.0` to restore the
historical sizes, or higher for HiDPI-at-distance or accessibility:

```nix
marchyo.theme.fontScale = 1.5; # everything ~50% larger
```

Each surface scales from its own base size and rounds to a whole number, so the
proportions between surfaces are preserved.

## Runtime theme switching

`marchyo.theme.themes` lists the themes available for **runtime** switching — no rebuild needed. Each listed theme's desktop assets (Waybar CSS, Mako config, Hyprland colors, Ghostty colors, wallpaper, GTK CSS + the dconf color-scheme) are pre-built into the system closure so a switch is an instant symlink swap. The default list is the Jylhis pair; add any tinted-schemes catalog name to make it switchable:

```nix
marchyo.theme.themes = [
  "jylhis-dark"
  "jylhis-light"
  "nord"
  "gruvbox-dark-hard"
];
```

### Inline catalog themes

An entry can also be an **inline base16 theme** — the catalog contract — so you
can add an arbitrary palette (an omarchy `colors.toml`, a matugen result, your
own) without it living in any upstream catalog. Provide the sixteen
`base00`..`base0F` slots and a polarity; every runtime surface is derived from
them, and an optional `wallpaper` overrides the default grid:

```nix
marchyo.theme.themes = [
  "jylhis-dark"
  {
    name = "kanagawa";
    variant = "dark";
    slots = {
      base00 = "#1f1f28"; base01 = "#2a2a37"; base02 = "#223249"; base03 = "#727169";
      base04 = "#c8c093"; base05 = "#dcd7ba"; base06 = "#938aa9"; base07 = "#363646";
      base08 = "#c34043"; base09 = "#ffa066"; base0A = "#dca561"; base0B = "#98bb6c";
      base0C = "#7fb4ca"; base0D = "#7e9cd8"; base0E = "#957fb8"; base0F = "#d27e99";
    };
    # wallpaper = ./kanagawa.png;  # optional; defaults to the Jylhis grid
  }
];
```

Runtime switching covers the directly-themed surfaces; Qt follows it too —
the session runs `QT_QPA_PLATFORMTHEME=gtk3`, so Qt apps pick up the swapped
`gtk.css` and dconf color-scheme on next launch. The remaining Stylix-derived
targets (fontconfig, GNOME/KDE bits) follow the build-time `variant`/`scheme`
until a rebuild. The switch is ephemeral — the next activation resets to the
declarative default.

GTK apps follow a runtime switch on next launch (newly started apps read the
swapped `~/.config/gtk-{3,4}.0/gtk.css`; libadwaita apps additionally restyle
live via the dconf color-scheme). Ghostty restyles **open** windows live too —
its runtime include names the Jylhis pair as a ghostty light/dark theme pair
(`theme = dark:…,light:…`), which ghostty resolves from the system
color-scheme, so the same dconf write that flips libadwaita apps recolors
running terminals. The Quickshell bar (`marchyo.shell.enable`)
recolors live as well — it reads the active theme's palette through the same
pointer — and `Super+Shift+L` cycles the theme from the compositor.

## Wallpaper

A generated Marchyo grid wallpaper is enabled by default wherever it is supported. To disable it, or to supply your own wallpaper asset package:

```nix
marchyo.theme.wallpaper = {
  enable = false;                    # skip the generated wallpaper
  # package = pkgs.my-wallpapers;   # or swap in a different asset package
};
```

## Wallpaper-derived theming (matugen)

`marchyo theme generate <image>` builds a colour scheme from a wallpaper with [matugen](https://github.com/InioX/matugen) and applies it live — no rebuild:

```bash
marchyo theme generate ~/Pictures/wall.jpg          # let matugen pick the polarity
marchyo theme generate ~/Pictures/wall.jpg --light  # force a light scheme
marchyo theme generate ~/Pictures/wall.jpg --dark   # force a dark scheme
marchyo theme generate --revert                     # back to the declarative theme
```

matugen extracts a base16 palette from the image, which Marchyo maps through the same token slots the catalog schemes use. It recolours the **runtime** surfaces instantly: the shell (bar, panels, toasts), the terminal (Ghostty), Hyprland window borders, `fzf`, and the wallpaper itself. (Generated themes do not restyle mako/waybar/GTK or `bat` — the matugen palette is the shell subset without the syn-* tokens those surfaces need, so they keep the previously active theme until the next `theme set` or rebuild.)

Qt follows the runtime GTK swap on next launch (`QT_QPA_PLATFORMTHEME=gtk3`),
and `starship` styles through ANSI slot names, so it already recolors with the
terminal's live palette. Other build-time surfaces themed through Stylix
(fontconfig, GNOME/KDE) keep the declarative theme until the next rebuild —
the same limitation every runtime theme switch has ([Runtime theme switching](#runtime-theme-switching)). Like `marchyo bg`, the generated theme is runtime-only: a rebuild (or `--revert`) resets to `marchyo.theme.variant`/`scheme`. Requires the desktop feature (matugen ships with it).

## Light mode

To use the light theme:

```nix
marchyo.theme = {
  variant = "light";
};
```

## Shell appearance scale

With the Quickshell shell (`marchyo.shell.enable = true`), a set of
palette-independent axes adjust the shell's geometry, corners, animation
speed, contrast, and overall shape without touching the colour palette.
The scale axes default neutral; the style axes (`floatingBar`,
`surfaceAlpha`) are Caelestia-inspired and default on.

```nix
marchyo.theme.appearance = {
  # floatingBar = false;     # full-width strip bar instead of the floating pill
  # surfaceAlpha = 1.0;      # opaque surfaces, no blur (default 0.85 glass)
  # cornerRadiusScale = 0.0; # square every corner (default 1.0)
  # uiScale = 1.2;           # larger chrome without changing font size
  # animationSpeed = 2.0;    # faster transitions (default 1.0)
  # highContrast = true;     # thicker panel/notification borders
};
```

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `floatingBar` | `bool` | `true` | Detached rounded pill bar with gaps to the screen edges; `false` restores the full-width strip |
| `surfaceAlpha` | `float` | `0.85` | Surface opacity; below `1` enables the Hyprland blur effect for the shell's layer surfaces (glass look) |
| `cornerRadiusScale` | `float` | `1.0` | Multiplier on corner radii (`0.0` squares corners) |
| `uiScale` | `float` | `1.0` | Geometry multiplier on top of `fontScale`, fonts unchanged |
| `animationSpeed` | `float` | `1.0` | Animation speed (higher is faster) |
| `highContrast` | `bool` | `false` | Thicker separators for higher-contrast chrome |
