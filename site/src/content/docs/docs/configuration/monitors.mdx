---
title: Monitors
description: Declaratively configure monitor outputs, resolution, position, and scale
---

`marchyo.monitors` declares your monitor layout as data. Each entry configures one output and is rendered into Hyprland's `monitor` table.

When the list is empty (the default), Marchyo keeps a single catch-all rule that auto-detects every connected output at its preferred mode, position `auto`, and scale `1` — the historical behaviour. Hosts that do not care about layout need set nothing.

## Options

Each entry in the `marchyo.monitors` list accepts:

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `output` | string | — (required) | Connector name as `hyprctl monitors` reports it, e.g. `"eDP-1"`, `"DP-1"`. `""` matches any unnamed output. |
| `enable` | bool | `true` | When `false`, the output is disabled and all other fields are ignored. |
| `mode` | string | `"preferred"` | `WIDTHxHEIGHT@HZ`, or `preferred` / `highres` / `highrr`. |
| `position` | string | `"auto"` | `Xx Y` (e.g. `"1920x0"`), or `auto` / `auto-right` / `auto-left` / `auto-up` / `auto-down`. |
| `scale` | number | `1.0` | Fractional scale (e.g. `1.5`, `2.0`). |
| `transform` | 0–7 | `0` | Rotation/flip. `1` = 90°, `2` = 180°, `3` = 270°; `4`–`7` are the flipped variants. Emitted only when non-zero. |
| `vrr` | 0–3 or null | `null` | Per-output adaptive sync: `0` off, `1` on, `2` fullscreen-only, `3` fullscreen-with-video. When `null`, the global `misc:vrr` applies. |
| `extraSettings` | attrset | `{}` | Extra key/value pairs merged verbatim into the output's monitor table (e.g. `bitdepth`, `mirror`). |

## Example

```nix
marchyo.monitors = [
  {
    output = "eDP-1";
    mode = "2256x1504@60";
    position = "0x0";
    scale = 1.5;
  }
  {
    output = "DP-1";
    mode = "3840x2160@144";
    position = "auto-right";
    scale = 2.0;
    vrr = 1;
    extraSettings.bitdepth = 10;
  }
];
```

## Disabling an output

```nix
marchyo.monitors = [
  { output = "eDP-1"; }          # laptop panel, defaults
  { output = "HDMI-A-1"; enable = false; }  # ignore the TV
];
```

## Per-monitor workspaces

`marchyo.workspaces.perMonitor` (default `true`) gives every monitor its own workspaces 1–10.
Hyprland numbers workspaces globally, so each monitor owns a block of ten ids: the first monitor 1–10, the next 11–20, and so on.
`Super + 1…0` go to a slot in the focused monitor's block, and each bar labels its monitor's workspaces 1–10.

- A block belongs to the physical monitor, matched by make, model and serial, not by connector. A monitor gets the same block each time it comes back.
- The laptop panel (`eDP*`, `LVDS*`, `DSI*`) takes the first free block. When `marchyo.monitors` is set, its enabled outputs claim blocks in list order first.
- When a monitor is unplugged, its workspaces with windows join the block of the monitor they land on. They return, under their old numbers, when it comes back.

The assignment is kept in `$XDG_STATE_HOME/marchyo/monitors/workspaces` (and `workspaces-merged` for the moved workspaces).
To start again, run:

```sh
marchyo monitor workspaces reset
```

This removes both files and reloads Hyprland, which gives the monitors plugged in now new blocks.

```nix
marchyo.workspaces.perMonitor = false;  # one global set of workspaces
```

## Display panel

The shell's display panel (global shortcut `panel.display`) shows one display at a time, with a button per display when there are several.
It sets:

- on/off, so long as another display stays on
- brightness: the laptop panel through `brightnessctl`, external monitors through `ddcutil` (see `marchyo.hardware.ddc`)
- scale, snapped to values the resolution divides into whole pixels
- resolution: the native one, then smaller modes of the same aspect ratio down to 1080p
- refresh rate, when the display offers a rate above 60 Hz at that resolution
- rotation: right-click a display in the layout map to turn it 0, 90, 180 and 270 degrees
- Extend or Mirror, for the built-in panel and the external displays

With more than one display the layout map appears. Drag a display to a side of another to place it. Dragging never leaves displays overlapping.
When a resolution, scale or rotation change makes a display larger or smaller, the displays next to it shift in the same step.

### Saved settings

The panel applies a change to Hyprland at once and saves it to `$XDG_STATE_HOME/marchyo/monitors/settings`, one line per display, keyed by make, model and serial rather than by connector, so a dock that renames its ports keeps each monitor's settings.
Hyprland loads the file after `marchyo.monitors`, so a choice made in the panel wins over the declarative entry, and a monitor that is plugged in later gets its saved settings.

The file is runtime state. It survives rebuilds, unlike `marchyo.monitors`.

- `marchyo monitor reset` deletes the file and reloads Hyprland, so `marchyo.monitors` decides again.
- `marchyo monitor save --nix` prints the current layout as a `marchyo.monitors` snippet, to make it declarative.

```nix
marchyo.monitorPanel.persist = false;  # the panel changes the session only; the file is not read or written
```
