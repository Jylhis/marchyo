---
title: Workstation Template
description: Bootstrap a full developer workstation configuration
---

Marchyo includes a workstation template that provides a complete developer setup with desktop environment, development tools, and sensible defaults.

## Getting started

### 1. Initialize the template

```bash
nix flake init -t github:Jylhis/marchyo#workstation
```

### 2. Generate hardware configuration

```bash
nixos-generate-config --show-hardware-config > hardware-configuration.nix
```

### 3. Customize `configuration.nix`

Edit the generated configuration:

- Change `networking.hostName` to your workstation name
- Update `marchyo.users.developer` with your details
- Set `marchyo.timezone` / `marchyo.defaultLocale` if the defaults
  (`Europe/Zurich`, `en_US.UTF-8`) don't fit
- Development tooling is a single switch — set
  `marchyo.development.enable = false` if you don't want it

### 4. Test in a VM (optional)

```bash
nixos-rebuild build-vm --flake .#workstation
./result/bin/run-workstation-vm
```

### 5. Build and switch

```bash
sudo nixos-rebuild switch --flake .#workstation
```

## What's included

### Desktop environment
- Hyprland (Wayland compositor) with all Marchyo customizations
- Ghostty terminal

### Development tools
- **Editors** — Emacs by default; switch via
  `marchyo.defaults.editor` (emacs, vscode, vscodium, zed) and
  `marchyo.defaults.terminalEditor` (emacs, neovim, helix, nano)
- **Version control** — Git with Git LFS, GitHub CLI
- **Containers** — rootless Podman with a `docker` compatibility shim, buildah, skopeo
- **Virtualization** — QEMU/KVM via libvirtd
- **Build & debug** — gnumake, cmake, gcc, jq/yq, nmap, tcpdump

### Terminal enhancements
- Starship prompt
- Zoxide (smart `cd`)
- fzf (fuzzy finder)
- ripgrep (fast `grep`)
- fd (fast `find`)

## Customization tips

### Adding programming languages

```nix
environment.systemPackages = with pkgs; [
  python3
  nodejs
  rustc cargo
  go
  jdk17
];
```

### VS Code extensions

```nix
programs.vscode = {
  enable = true;
  extensions = with pkgs.vscode-extensions; [
    ms-python.python
    rust-lang.rust-analyzer
  ];
};
```

### Using Docker instead of Podman

```nix
marchyo.development.containers.backend = "docker";
```

See [Feature Flags](/docs/configuration/feature-flags/#container-backend-and-the-docker-group) for the `docker` group trade-off.

### Project-specific dev shells with direnv

`marchyo.development.enable` already installs direnv with nix-direnv. In your project directory, create a `.envrc`:

```bash
use flake
```

### Multi-monitor setup

Describe your outputs in `marchyo.monitors` (see [Monitors](/manual/12-monitors/)):

```nix
marchyo.monitors = [
  { output = "DP-1"; mode = "1920x1080@60"; position = "0x0"; }
  { output = "HDMI-A-1"; mode = "1920x1080@60"; position = "1920x0"; }
];
```

### Extra environment variables

`env` entries must use the two-argument form. The legacy hyprlang shape
(`{ n = ...; v = ...; }`) renders as a single-table call that aborts
Hyprland's config load, so Marchyo rejects it at eval time:

```nix
wayland.windowManager.hyprland.settings.env = [
  { _args = [ "HYPRCURSOR_THEME" "Bibata-Modern-Classic" ]; }
];
```

## Updating

```bash
nix flake update
sudo nixos-rebuild switch --flake .#workstation
```
