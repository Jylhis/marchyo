## Quake console

`special:qconsole` is a terminal that drops down over the top half of the
focused monitor. The first time it opens it runs `$AI_AGENT` (set by
`marchyo.defaults.aiAgent`) and falls back to a shell. A console with one
tiled window is boxed into a centred panel twice as wide as it is tall.
Opening a second app gives it the full width.

- `Super+grave` toggles the console.
- `Super+Shift+grave` moves the focused window into it.

## herdr

[herdr](https://herdr.dev) manages terminal workspaces for AI coding agents.
When enabled, marchyo installs it, runs `herdr server` as a user service,
binds `Super+Ctrl+Return` to open herdr in the terminal, and runs
`herdr integration install <agent>` once per login for each installed agent
CLI (claude, codex, opencode, pi, grok).

## Amp

`amp-cli` and `amp-desktop` are unfree. Enabling either option fails with a
message when `nixpkgs.config.allowUnfree` is false.

## Agent skills

`marchyo.ai.skills.enable` installs three skills into the skill directories of
Claude Code (`~/.claude/skills`), Codex (`~/.codex/skills`) and opencode
(`~/.config/opencode/skills`):

- `marchyo`: the CLI, theming, keybinds, Hyprland and the shell.
- `marchyo-plugin`: writing and packaging a shell plugin.
- `diagnose-crash`: investigating a core dump with `coredumpctl` and the NixOS
  debuginfod server. Adapted from Omarchy (MIT).

Accounts from `marchyo agent account` link their `skills` directory to the
primary home, so they see the same skills. The option defaults to on while an AI
coding agent is installed.

## Crash capture

A user service, `marchyo-crash-watch`, follows the journal for systemd-coredump
entries of your own processes and sends a critical notification with a
**Diagnose** action. The action runs `marchyo agent crash <pid> [comm] [exe]
[signal] [timestamp]`, which opens `$AI_AGENT` in a terminal with a prompt that
points at the `diagnose-crash` skill. Only dumps logged by `systemd-coredump`
count, so another program of yours cannot forge one. The agent starts in its most
restricted approval mode (Claude Code `--permission-mode default`, Codex
read-only sandbox with `untrusted` approvals, the opencode `plan` agent) and runs
in its own transient unit, so `marchyo toggle crash-capture off` leaves an open
diagnosis alone. Each program is announced at most once per `dedupeSeconds`, at
most three programs a minute and five open notifications at a time. Stop it for
the session with `marchyo toggle crash-capture off`.

## Agent usage

`marchyo agent usage` and the agents panel show limits for Claude Code, Codex,
GitHub Copilot, Z.ai (Coding Plan, with `ZAI_API_KEY`) and OpenRouter (the key's
spending limit, with `OPENROUTER_API_KEY`). A provider without a key is skipped.

## Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `marchyo.console.enable` | `bool` | `true` | Quake console on the desktop |
| `marchyo.ai.herdr.enable` | `bool` | `false` | herdr CLI, server service, bind and agent integrations |
| `marchyo.ai.herdr.desktop.enable` | `bool` | `false` | herdr desktop app (`herdr-app`) |
| `marchyo.ai.amp.enable` | `bool` | `false` | Amp CLI (`amp-cli`) |
| `marchyo.ai.amp.desktop.enable` | `bool` | `false` | Amp desktop app (`amp-desktop`) |
| `marchyo.ai.skills.enable` | `bool` | an agent is installed | Install the marchyo, marchyo-plugin and diagnose-crash skills |
| `marchyo.ai.crashCapture.enable` | `bool` | desktop and an agent | Crash watcher with a Diagnose notification |
| `marchyo.ai.crashCapture.ignore` | `str` | `""` | Extended regex of executable basenames never announced |
| `marchyo.ai.crashCapture.dedupeSeconds` | `unsigned int` | `60` | Announce a crashing program at most once per window |

```nix
marchyo.defaults.aiAgent = "claude-code";
marchyo.ai.herdr.enable = true;
```
