---
title: Graphics (GPU)
description: Configure GPU vendors, NVIDIA drivers, and hybrid graphics
---

Marchyo supports Intel, AMD, and NVIDIA GPUs, including hybrid graphics configurations with NVIDIA PRIME.

## GPU vendors

Specify which GPU vendors are present in your system:

```nix
marchyo.graphics.vendors = [ "intel" ];
```

For hybrid graphics laptops with two GPUs:

```nix
marchyo.graphics.vendors = [ "intel" "nvidia" ];
```

:::note
Find your GPU with: `lspci | grep -E 'VGA|3D'`
:::

| Vendor | Description |
|--------|-------------|
| `"intel"` | Intel integrated graphics (iGPU) |
| `"amd"` | AMD GPUs (integrated or discrete) |
| `"nvidia"` | NVIDIA discrete GPUs |

When `vendors` is empty (default), Intel packages are applied on x86_64 for backward compatibility. If `vendors` is left empty while `marchyo.desktop.enable = true`, evaluation emits a warning telling you to set `vendors` explicitly (e.g. `["nvidia"]` or `["amd"]`).

## NVIDIA options

- `marchyo.graphics.nvidia.generation` (`"turing-or-newer"` or `"pre-turing"`, default `"turing-or-newer"`): the GPU generation. Turing is RTX 20xx and GTX 16xx. Pre-Turing is Maxwell, Pascal and Volta.
- `marchyo.graphics.nvidia.package` (`"stable"`, `"beta"`, `"production"` or `"legacy_580"`): the driver branch from `boot.kernelPackages.nvidiaPackages`. The default is `"stable"`, or `"legacy_580"` for pre-Turing GPUs.
- `marchyo.graphics.nvidia.open` (bool): use the open kernel modules. The default is `true` for Turing or newer and `false` for pre-Turing. RTX 50xx requires them.
- `marchyo.graphics.nvidia.powerManagement` (bool, default `false`): experimental power management (may improve laptop battery life).
- `marchyo.graphics.nvidia.containerToolkit.enable` (bool): enable `hardware.nvidia-container-toolkit`, so containers get the GPU through CDI (`podman run --device nvidia.com/gpu=all ...`). The default is `true` when `"nvidia"` is in `vendors` and `marchyo.development.enable` is set.

```nix
marchyo.graphics.nvidia = {
  generation = "turing-or-newer";
  package = "stable";
  powerManagement = false;
};
```

:::caution
`nvidia.open = true` with `generation = "pre-turing"` fails evaluation. The open modules support only Turing and newer.
:::

### NVIDIA environment variables

- `NVD_BACKEND` is `direct` on Turing or newer and `egl` on pre-Turing.
- `__GLX_VENDOR_LIBRARY_NAME=nvidia` and `GBM_BACKEND=nvidia-drm` are set only when NVIDIA drives the display: NVIDIA is the only GPU, or PRIME runs in `sync` mode.
- `LIBVA_DRIVER_NAME=nvidia` is set under the same condition, and only on Turing or newer.

In PRIME `offload` and `reverse-sync` modes the integrated GPU drives the display, so these variables stay unset. Forcing them there breaks video in Chromium-based browsers.

## AMD options

- `marchyo.graphics.amd.vaapi.enable` (bool, default `true`): Mesa radeonsi VA-API and VDPAU, plus `vainfo`. `LIBVA_DRIVER_NAME=radeonsi` and `VDPAU_DRIVER=radeonsi` are set only when AMD is the primary GPU (no Intel iGPU, and NVIDIA does not drive the display).
- `marchyo.graphics.amd.overdrive.enable` (bool, default `false`): set `hardware.amdgpu.overdrive.enable` for overclocking and undervolting tools such as LACT or CoreCtrl.
- `marchyo.graphics.amd.rocm.enable` (bool, default `false`): the ROCm compute stack. It installs the HIP runtime (`rocmPackages.clr`), links it to `/opt/rocm/hip`, and adds Marchyo users to the `render` and `video` groups. It requires `"amd"` in `vendors`.
- `marchyo.graphics.amd.rocm.hsaOverrideGfxVersion` (string or null, default `null`): the value of `HSA_OVERRIDE_GFX_VERSION`, for GPUs that ROCm does not officially support (for example `"10.3.0"` for RDNA2 or `"11.0.0"` for RDNA3).

```nix
marchyo.graphics = {
  vendors = [ "amd" ];
  amd.rocm = {
    enable = true;
    hsaOverrideGfxVersion = "11.0.0";
  };
};
```

## NVIDIA PRIME (hybrid graphics)

For laptops with both an integrated GPU and a discrete NVIDIA GPU:

```nix
marchyo.graphics = {
  vendors = [ "intel" "nvidia" ];

  prime = {
    enable = true;
    intelBusId = "PCI:0:2:0";
    nvidiaBusId = "PCI:1:0:0";
    mode = "offload";
  };
};
```

### Finding bus IDs

Run `lspci | grep -E 'VGA|3D'` and convert hex bus IDs to the `PCI:bus:device:function` format (convert hex values to decimal).

### PRIME options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `marchyo.graphics.prime.enable` | `bool` | `false` | Enable NVIDIA PRIME |
| `marchyo.graphics.prime.intelBusId` | `string` | `""` | PCI bus ID of Intel iGPU |
| `marchyo.graphics.prime.amdgpuBusId` | `string` | `""` | PCI bus ID of AMD iGPU |
| `marchyo.graphics.prime.nvidiaBusId` | `string` | `""` | PCI bus ID of NVIDIA dGPU |
| `marchyo.graphics.prime.mode` | `string` | `"offload"` | PRIME render mode |

### PRIME modes

| Mode | Description |
|------|-------------|
| `"offload"` | On-demand rendering (default). Power efficient — use `nvidia-offload <command>` to run apps on the discrete GPU. |
| `"sync"` | Always use discrete GPU. Best performance but more power consumption. |
| `"reverse-sync"` | iGPU for display, dGPU for compute. |

### PRIME requirements

Enabling PRIME is validated with assertions — the build fails with a clear
message if any of these are not met:

- `vendors` must contain `"nvidia"` **and** an iGPU vendor (`"intel"` or `"amd"`)
- `prime.nvidiaBusId` must be set
- `prime.intelBusId` must be set when `"intel"` is in `vendors`
- `prime.amdgpuBusId` must be set when `"amd"` is the iGPU (i.e. `"amd"` in `vendors` without `"intel"`)

### Integrated-only boot entry

On a hybrid laptop, set `prime.integratedOnlySpecialisation = true` to add an `integrated-only` boot specialisation:

```nix
marchyo.graphics.prime.integratedOnlySpecialisation = true;
```

The specialisation turns off PRIME, blacklists the `nvidia`, `nvidia_modeset`, `nvidia_uvm`, `nvidia_drm` and `nouveau` kernel modules, and removes the NVIDIA environment variables and the container toolkit. Use it to save battery when you do not need the discrete GPU.

Select the `integrated-only` entry in the systemd-boot menu. When the menu is hidden (`boot.loader.timeout = 0`), hold Space while the machine boots to show it. The option requires `prime.enable`.

## Examples

### Intel-only desktop

```nix
marchyo.graphics.vendors = [ "intel" ];
```

### AMD-only desktop

```nix
marchyo.graphics.vendors = [ "amd" ];
```

### NVIDIA desktop

```nix
marchyo.graphics = {
  vendors = [ "nvidia" ];
  nvidia.open = true;
};
```

### Intel + NVIDIA laptop (offload)

```nix
marchyo.graphics = {
  vendors = [ "intel" "nvidia" ];
  nvidia.open = true;
  prime = {
    enable = true;
    intelBusId = "PCI:0:2:0";
    nvidiaBusId = "PCI:1:0:0";
    mode = "offload";
  };
};
```

### AMD + NVIDIA laptop (sync)

```nix
marchyo.graphics = {
  vendors = [ "amd" "nvidia" ];
  nvidia.open = true;
  prime = {
    enable = true;
    amdgpuBusId = "PCI:6:0:0";
    nvidiaBusId = "PCI:1:0:0";
    mode = "sync";
  };
};
```
