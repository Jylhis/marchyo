---
title: Local models (Ollama)
description: Run local language models with Ollama and point opencode at them
---

`marchyo.ai.local` runs an Ollama server and picks the build that matches the GPU.

```nix
marchyo.ai.local = {
  enable = true;
  models = [ "qwen3:8b" ];
};
```

## Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `marchyo.ai.local.enable` | `bool` | `false` | Run Ollama |
| `marchyo.ai.local.models` | `list of str` | `[]` | Models pulled at start (`services.ollama.loadModels`) |
| `marchyo.ai.local.host` | `str` | `"127.0.0.1"` | Listen address |
| `marchyo.ai.local.port` | `port` | `11434` | Listen port |
| `marchyo.ai.local.acceleration` | `null` or `"cuda"`, `"rocm"`, `"cpu"` | `null` | Ollama build; `null` selects it from `marchyo.graphics` |

## Package selection

With `acceleration = null`:

- `nvidia` in `marchyo.graphics.vendors`: `ollama-cuda`. NVIDIA wins on machines with both vendors.
- `amd` in `marchyo.graphics.vendors` and `marchyo.graphics.amd.rocm.enable`: `ollama-rocm`. `marchyo.graphics.amd.rocm.hsaOverrideGfxVersion` becomes `services.ollama.rocmOverrideGfx`.
- Otherwise: `ollama`.

Set `acceleration` to force a build. `"cpu"` selects `ollama-cpu`. CUDA builds need `nixpkgs.config.allowUnfree`.

## opencode

When `marchyo.defaults.aiAgent = "opencode"` and `marchyo.development.enable` are set, Home Manager adds an `ollama` provider to opencode. It uses the OpenAI-compatible endpoint `http://<host>:<port>/v1` and lists `models`. A wildcard `host` (`0.0.0.0` or `::`) connects through `127.0.0.1`.

Other agents are not configured.
