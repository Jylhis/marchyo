## Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `marchyo.timezone` | `string` | `"Europe/Zurich"` | System timezone |
| `marchyo.defaultLocale` | `string` | `"en_US.UTF-8"` | System default locale |
| `marchyo.language` | `enum` | derived from `marchyo.defaultLocale` | Display language of the Marchyo shell and CLI strings |
| `marchyo.autoTimezone.enable` | `bool` | `false` | Update the timezone automatically from your location |

## Example

```nix
{
  marchyo.timezone = "America/New_York";
  marchyo.defaultLocale = "de_DE.UTF-8";
}
```

## Display language

`marchyo.language` sets the language of Marchyo's own UI: the shell panels and the `marchyo` CLI messages. The default follows `marchyo.defaultLocale` (`fi_FI.UTF-8` gives `fi`, `pt_BR.UTF-8` gives `pt-BR`) and falls back to `"en"` when the locale has no entry in the registry. Strings without a translation show in English.

```nix
{
  marchyo.defaultLocale = "fi_FI.UTF-8";
  marchyo.language = "fi"; # optional, same as the derived default
}
```

The system `LANG` changes only when you rebuild. `marchyo language` changes the Marchyo UI live, without a rebuild:

```bash
marchyo language          # show the current language
marchyo language list     # list the supported codes
marchyo language de       # switch the shell and CLI to German
marchyo language --revert # back to marchyo.language
```

The command stores a runtime override that survives rebuilds and `marchyo runtime restore`; `--revert` drops it. Other programs keep following `LANG`.

## Automatic timezone

`marchyo.autoTimezone.enable` is opt-in and off by default. When enabled, it turns on `services.automatic-timezoned` (a geoclue2-based daemon) to keep the system timezone current based on your location:

```nix
{
  marchyo.autoTimezone.enable = true;
}
```

:::note
  With automatic timezone enabled, the daemon wins over the static `marchyo.timezone`. If you also change `marchyo.timezone` from its default, evaluation emits a warning that the static value is ignored.
:::

## Common timezones

| Timezone | Region |
|----------|--------|
| `"Europe/Zurich"` | Central Europe (default) |
| `"Europe/London"` | United Kingdom |
| `"Europe/Helsinki"` | Finland |
| `"America/New_York"` | US Eastern |
| `"America/Los_Angeles"` | US Pacific |
| `"Asia/Tokyo"` | Japan |
| `"Asia/Shanghai"` | China |
