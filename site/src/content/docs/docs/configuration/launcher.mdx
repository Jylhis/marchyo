---
title: Launcher
description: The application launcher of the Marchyo shell (marchyo.shell)
---

The Marchyo shell includes the launcher. Three binds open it:
**`Super+R`** (apps), **`Super+period`** (emoji picker), and
**`Super+Ctrl+V`** (clipboard history).

The launcher finds apps from the freedesktop entries, emoji from the Unicode
catalog, and clipboard entries from cliphist. It takes its colours from the
design tokens at runtime. It pastes with `wtype`, so it needs **no privileged
helper**.

The launcher is **on by default** with `marchyo.desktop.enable`. The binds also
need `marchyo.shell.enable`; without the shell, Marchyo does not bind them.

## Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `marchyo.launcher.enable` | `bool` | `true` with desktop | Bind the in-shell launcher |

The Vicinae options `marchyo.launcher.keybinding`, `inputServer`, `telemetry`,
`declutter`, and `settings` are retired. A definition of one of them fails the
evaluation with a pointer to the in-shell launcher.
